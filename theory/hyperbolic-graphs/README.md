# Hyperbolic graphs / Гиперболические графы

This bilingual path introduces the geometry and learning methods used for
hierarchical graphs. Every English section is followed by its Russian version.

Этот двуязычный курс знакомит с геометрией и методами обучения для
иерархических графов. За каждым разделом на английском следует версия на
русском языке.

## Learning path / План изучения

1. [Foundations and the Poincaré ball / Основы и шар Пуанкаре](01-foundations.md)
2. [Embeddings and hyperbolic GNNs / Эмбеддинги и гиперболические GNN](02-learning.md)
3. [Executable example / Исполняемый пример](../../examples/hyperbolic_graph_basics.ipynb)

## Outcomes / Результаты обучения

After these notes, you should be able to explain why hyperbolic space represents
trees efficiently, compute Poincaré distance, and identify the extra operations
and numerical safeguards needed by a hyperbolic GNN.

После изучения материалов вы сможете объяснить, почему гиперболическое
пространство эффективно представляет деревья, вычислить расстояние Пуанкаре и
назвать дополнительные операции и меры численной устойчивости для
гиперболической GNN.
